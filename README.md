# 数派！· 人教版三年级上册

让数学拍出节奏。支持基础与进阶练习、按单元和知识点练习、知识地图、过关奖励及练习日历；默认炫彩，保留浅色主题和音量调节。

在线体验：[数派三上](https://kevinlin20219-cell.github.io/shupai-three/)

## 版本与运行

2026-11-07 从已发布三上站点的静态文件发布，来源版本 `8b7ff700483e4fd6457cf40c785a33ad6e6e406d`。网页 HTML、CSS、ES 模块及资源均位于仓库根目录；无需构建，可用 `python3 -m http.server 8080` 本地运行。Pages 使用 `main` 分支根目录。

课程以用户核对的人教版三上7个单元、2个实践活动为准。进阶优先采用已核读浙江地区试卷的题型改编，不足时补同步自编题；参考资料是公开转载，不宣称经学校官方原卷认证。

学习记录、错题、奖励与日历保存在当前浏览器，换域名不会自动迁移。
